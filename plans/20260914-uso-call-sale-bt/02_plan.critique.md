## Additional observations (non-blocking)

- Task count is 6 (T2 optional), inside the 5–8 bound; effort is one S, four M, one L (T5). The plan introduces an `L` unit (3–8 h) for the backtest only, stated in Soft constraints; the previous plans' S/M scale is otherwise kept. Deadlines run Thu 2026-09-17 → Thu 2026-09-24, none on plan day, honoring "not for today execution" and leaving the desk free through the FOMC / BOJ week for the closed plan's watch.
- The central methodological call is A5 / F-b: the absolute levels S1–S4 (≈ 140–175) and wall 160 have little or no history in the split-adjusted USO series, so a literal backtest of those prices has n ≈ 0. The plan therefore tests the **rule class** — PA's mechanical zone rule applied walk-forward — and says so in `## Out of scope`, `## Zone generation`, and `## Caveats`. This is why T1 is a *versioned historical* spec (rule + formation dates + version) rather than a level list: the formation date is what makes walk-forward possible, and the version is what lets `REPORT.md` cite exactly which rule was tested.
- Honesty is enforced by flags rather than prose: `PREMIUM:MODELED` (no options chain; BS with OVX), `ZONE:PROXY` (discretionary PA rule mechanized), `WALL:NA` (no UW history), `LOW-N` / `NO-READ` (n thresholds), `SENS` (bounded sensitivity, never selection). Each is a greppable literal with a rule for when it must appear, and the REPORT's `## Caveats` is a single section so the caveats are stated once, matching the brief's "not sermons" tone.
- Hit rate is deliberately path-based (short strike not breached at a daily close) so Dominic's most robust number does not depend on the premium model; avg R and max DD do and carry the flag (F-c). The two numbers are thus of different reliability, and the plan says so where the numbers are produced.
- The no-search rule is structural, not aspirational: T3 and T4 precede T5 in the dependency graph, parameters written there are the pre-registered set, and `SENS` is bounded to ≤ 2 parameters × ±1 step in its own section. This matches the desk's earlier "no parameter search" discipline from the independent-retest plan.
- `AI-up` and `OE reject` are carried as PA's tokens without expansion. PA defines them on the chart (T1), RA mechanizes them (T4), and the S1 historical-label sample is what lets T5 report proxy agreement instead of assuming it. If agreement is poor, the REPORT states it in `## Caveats` — the regime split is then a weaker read, not a re-fit.
- `C4` wall-fade is the one strategy the plan expects to return `NA` (F-f): a static 160 cannot be backtested, and only UW's optional history can change that. The S4 forward paper-journal proposal is the constructive substitute, kept as a proposal with an approval line so it cannot become a routine change by default.
- Risk to watch: A1 (inferred host-Sequence order). The plan cannot see the Sequence text and says so; the mitigation is a single header line RA writes in T3 (`host_sequence:`) and a version-2 path that keeps `plan_id` fixed. Nothing in the file renames or renumbers anything, so a mismatch is a one-line correction rather than a re-issue.
- Status is `ready` as instructed: the host Sequence is already issued, the header note and Changelog make the formalization role explicit, and no owner receives new work from this file that they have not already been sent.
