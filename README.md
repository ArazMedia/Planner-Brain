# Planning scratchpad

This repo holds **plan drafts only** (`plans/<plan_id>/02_plan.md` and `02_plan.critique.md`), written by the planning brain from a brief.

Nothing here is executed from this repo. The Planner reviews these drafts and pastes the outputs into `/workspace/plans` on the desk, where MHM and the other bots pick them up. Execution artifacts live under the paths named inside each plan (for example `/workspace/mhm/research/<topic>/`), never here.
